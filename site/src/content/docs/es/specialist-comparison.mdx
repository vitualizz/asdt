# Comparación de especialistas

Usá esta comparación para elegir el especialista correcto en menos de 60 segundos. Desplegá cualquier fila de abajo para ver cuándo invocar a ese especialista, qué produce, cuándo NO usarlo y un comando de ejemplo. AC (acceptance criteria, o "criterios de aceptación" — la lista que define cuándo algo está "terminado") y CWE (un catálogo público de tipos comunes de vulnerabilidades) aparecen en algunas filas más abajo.

### Recuperación: elegiste el especialista equivocado

Detené la corrida actual. Invocá directamente al especialista correcto — cada especialista lee automáticamente los artefactos previos desde la base de conocimiento compartida. No se pierde nada de la corrida interrumpida.

Ejemplo: si corriste `/asdt-developer` antes de crear un ADR, corré `/asdt-architect` para producir el registro de decisión, y después volvé a invocar `/asdt-developer`. El Developer va a leer el ADR automáticamente en su próxima corrida.

Mirá [Solución de problemas](/asdt/docs/troubleshooting) para procedimientos de recuperación paso a paso.
