# Índice de skills

Todos los especialistas de ASDT de un vistazo, en orden de pipeline. Cada uno es invocable de forma independiente con su comando — usá esta grilla para elegir el especialista correcto cuando solo necesitás una perspectiva.

<SkillsIndex t={t} locale="es" />

Cuando el trabajo abarca múltiples perspectivas, salteá la grilla y ejecutá `/asdt <descripción del feature>` — el orquestador clasifica el cambio y lo enruta por los especialistas correctos en el orden correcto.
