# Comenzando

## Requisitos

Antes de usar ASDT necesitás:

- **Claude Code** u **OpenCode** — instalado y autenticado (son los únicos asistentes que ASDT soporta hoy)
- **Un memory provider** (opcional, recomendado) — lleva el conocimiento clave del proyecto (decisiones, convenciones, lecciones) de una sesión a otra. El instalador ofrece [Engram](https://github.com/Gentleman-Programming/engram). Sin uno, ASDT igual funciona dentro de cada sesión
- **Un provider de code intelligence** (opcional) — un índice de tu código que responde preguntas de símbolos y estructura en una llamada, en vez de bucles de grep y lectura. El instalador ofrece [Codegraph](https://github.com/Gentleman-Programming/codegraph). Sin uno, los especialistas usan grep y lectura
- Una terminal (bash o zsh)

> **¿Compilando desde el código fuente?** Se requiere Go 1.22+. El instalador de una línea descarga un binario precompilado — no necesitás compilador.

## Instalación

```bash
curl -fsSL https://raw.githubusercontent.com/vitualizz/asdt/main/install.sh | bash
```

Descarga el último binario precompilado (`asdt-tui`) para tu plataforma e instala en `~/.local/bin/`. No necesitás Go ni compilador.

> Si `~/.local/bin` no está en tu `PATH`, el instalador te muestra la línea exacta para agregar a tu shell profile.

## Ejecutá el instalador

```bash
asdt-tui
```

`asdt-tui` es una interfaz interactiva de terminal. Desde el menú principal, elegí **Install / Update Skills** y te guía por un flujo corto:

1. **Idioma** — elegí el idioma en el que habla ASDT: `en` (inglés), `es-419` (español latinoamericano) o `es-ES` (español de España). Tu elección aplica tanto a la interfaz del instalador como a los especialistas instalados.
2. **Chequeo del entorno** — verifica tu sistema operativo, shell, cada memory provider (Engram) y cada provider de code intelligence (Codegraph). Nada acá te bloquea: si falta un provider, ves una advertencia con su link de instalación.
3. **Asistentes** — elegí a cuál apuntar: **Claude Code**, **OpenCode** o ambos. Cada uno muestra una insignia de presente/faltante.
4. **Providers** — una pantalla, dos elecciones. **Memoria**: elegí Engram o **Sin memoria**. Por defecto queda Engram si está en tu `PATH`, y si no, Sin memoria. Podés elegir Engram antes de instalarlo: el instalador te avisa y muestra el link de instalación, y la memoria funciona en cuanto Engram esté conectado. Se recomienda un provider porque conserva el conocimiento clave del proyecto entre sesiones. **Inteligencia de código**: elegí Codegraph o **Sin inteligencia de código**, con el mismo criterio por defecto. Los especialistas consultan el índice solo en un proyecto que indexó; en cualquier otro caso usan grep y lectura.
5. **Preset de modelo** — elegí cuánta potencia de modelo usa cada paso de los especialistas (ver abajo).
6. **Persona** — opcionalmente elegí una persona para los asistentes instalados, y si deben usar emojis. Se escribe en tu `CLAUDE.md` / `AGENTS.md` global como un único bloque marcado; el resto del archivo nunca se toca. Si el archivo ya existe, elegís por asistente si actualizar el bloque de ASDT u omitirlo. Podés saltar este paso por completo (mirá [La configuración del agente](/asdt/es/docs/ai-assistants#la-configuración-del-agente-ambos)).
7. **Permisos** — una barrera opt-in para el overlay de permisos de Claude Code. Rechazar es el valor por defecto seguro y no escribe nada.
8. **Review → Install → Done** — confirmá tus selecciones, mirá correr la instalación y listo. El **Dashboard** del menú principal muestra el estado por asistente en cualquier momento, y quita el bloque de configuración del agente de ASDT (`r`) cuando ya no lo quieras.

## Inicializá tu proyecto

Abrí tu asistente de IA en la carpeta de tu proyecto y ejecutá:

```
/asdt-init
```

Detecta tu stack, hace un par de preguntas, y escribe `.asdt/config.yaml` con valores por defecto razonables.

## Tu primer pipeline

```
/asdt Agregar autenticación de usuario con email y contraseña
```

ASDT analiza la petición y recomienda una secuencia de especialistas — por ejemplo: `/asdt-pm` → `/asdt-architect` → `/asdt-developer`. Si decís que sí, corre esa cadena de a un especialista por vez y hace una pausa después de cada uno para que puedas discutir; o ejecutás vos cada comando. El resumen de cada especialista va al scratchpad de la sesión, así el siguiente retoma donde dejó el anterior.

## Ejecutar especialistas individuales

```
/asdt-pm Agregar modo oscuro a la página de configuración
/asdt-architect Diseñar la estrategia de caché
/asdt-developer Implementar el componente de perfil de usuario
```
